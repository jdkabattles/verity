Verity

An append-only evidence ledger for agent runs. A claim is accepted only when the recorded result supports it.

View on GitHub How to use 
verity init --run verity.jsonl
verity log --run verity.jsonl --kind tool_result --data '{"text":"9 passed, 0 failed"}'
verity claim --run verity.jsonl --statement "the bot tests passed" --evidence 1
verity verify --run verity.jsonl

What it checks

  • Every line is hashed to the previous line. Edit one and verity verify fails.
  • A claim must cite an observation or a tool result.
  • 9 passed, 0 failed supports a pass claim. binary found does not.

How a real run looks

Point it at a project. Run the tests. Log the output. Claim only what that output supports.

cd your-project
verity init --run verity.jsonl
verity log --run verity.jsonl --kind goal --data '{"text":"run the tests and report the real result"}'
# run the suite, then log the real output
verity log --run verity.jsonl --kind tool_result --data '{"text":"9 passed, 0 failed"}'
verity claim --run verity.jsonl --statement "the bot tests passed" --evidence 1
printf '%s\n' '{"must_claim":["the bot tests passed"]}' > spec.json
verity check --run verity.jsonl --spec spec.json

A passing check means this run is intact and the claim is supported. It does not mean the next run will pass.
